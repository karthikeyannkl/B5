BORNTOWIN5 — FINAL PERMANENT DATABASE BUILD

Purpose
-------
AIC Cloud remains the web/server host. Supabase is the permanent database.
The existing Member/Admin UI is preserved. This package changes the persistence layer only.

AIC Environment Variables required
----------------------------------
SUPABASE_URL=https://<your-project-ref>.supabase.co
SUPABASE_SECRET_KEY=sb_secret_...   (backend only; never put in HTML/GitHub)

Existing SMTP variables remain unchanged:
SMTP_HOST
SMTP_PORT
SMTP_USER
SMTP_PASS
EMAIL_FROM

Do NOT add /rest/v1/ to SUPABASE_URL.
Do NOT use DATABASE_URL for this build.
Do NOT delete/reset the Supabase app_state table.

Supabase one-time SQL (already done if app_state exists and is exposed)
-----------------------------------------------------------------------
GRANT SELECT, INSERT, UPDATE, DELETE
ON TABLE public.app_state
TO service_role;

Deployment
----------
Replace server.js, member.html, admin.html and package.json in the existing AIC project.
Keep the existing repository data/db.json if it contains the current testing data.

First startup behavior
----------------------
1. If Supabase already has real app_state data, it loads it and preserves it.
2. If Supabase app_state is empty but the existing local db.json has real testing data, it seeds Supabase ONCE.
3. If both are empty, startup stops instead of creating an empty database.
4. Future writes update Supabase; local db.json is only a local cache.
5. No automatic delete/reset is performed.

Verification
------------
Open /api/db-status after deployment. It should return ok:true and persistence:"supabase-api".
Then test one existing member login and one new test write before launch.
